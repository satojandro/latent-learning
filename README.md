# Latent Learning

A storybook about what happens inside AI models, for curious adults and ambitious teenagers.

Each chapter retells one paper from [transformer-circuits.pub](https://transformer-circuits.pub) using plain language, a recurring cast of characters and interactive toys. Some of the toys are real models training live in your browser. Read in order, the chapters tell the story of how mechanistic interpretability has developed.

This is an independent, unofficial project. It isn't affiliated with or endorsed by Anthropic or the papers' authors.
